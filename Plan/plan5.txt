Setup Phaser 3 di dalam React untuk game farming pixel art:

SPESIFIKASI VISUAL:
- Resolusi internal canvas: 320x180
- Scale up otomatis (FIT) memenuhi layar dengan letterbox
- pixelArt: true, antialias: false
- image-rendering: pixelated di CSS
- Tile size: 16x16 pixel

STRUKTUR PHASER:
- BootScene: preload assets (placeholder: warna solid + emoji)
- MainScene: 
  * Render map 30x20 tile (rumput hijau, tanah coklat, jalan)
  * Render sumur (biru, di posisi tetap)
  * Render toko (coklat, di posisi tetap)
  * Render crops dari state backend
  * Player sprite (4 arah)
  * Camera follow player

PLAYER:
- Kecepatan: 80 px/detik
- Animasi walk (bobbing sederhana)
- Kontrol: WASD + Arrow keys
- Arah hadap disimpan (untuk interaksi E)

INTEGRASI REACT:
- Komponen <GameCanvas /> di src/game/GameCanvas.tsx
- useEffect untuk init Phaser game, cleanup saat unmount
- Phaser events → Zustand store → React UI update
  Contoh: saat player bergerak, update posisi tile aktif di store

DELIVERABLE:
- GameCanvas.tsx (React wrapper Phaser)
- BootScene.ts, MainScene.ts
- Player.ts (class atau komponen Phaser)
- Placeholder sprite (bisa pakai Graphics Phaser untuk warna solid)
- Kontrol keyboard berfungsi
- Kamera smooth follow
