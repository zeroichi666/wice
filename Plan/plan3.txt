Implementasi autentikasi API untuk game farming dengan Laravel Sanctum:

ENDPOINTS (/api/v1):
- POST /register → { username, email, password, password_confirmation }
- POST /login    → { email, password }
- POST /logout   → (auth required)
- GET  /me       → return data user + coins + level

VALIDASI:
- register: username min 3 max 20, email valid, password min 8
- login: email & password wajib

RESPONSE:
- Sukses register: auto-login, set cookie Sanctum, return user data
- Sukses login: set cookie Sanctum, return user data
- Gagal: 422 dengan errors

KEAMANAN:
- Rate limit login (5x per menit)
- Password hashing bcrypt
- CORS config untuk frontend (Vite dev server: localhost:5173)

DELIVERABLE:
- AuthController di app/Http/Controllers/Api/V1
- Form Request: RegisterRequest, LoginRequest
- Route di routes/api.php dengan prefix /v1
- Konfigurasi CORS & Sanctum
- Test endpoint dengan Postman/curl (sertakan contoh request)
