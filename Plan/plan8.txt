Implementasi menanam bibit:

BACKEND:
POST /api/v1/game/plant
Request: { tile_x, tile_y, seed_code }

Validasi:
1. Tile sudah di-till (ada di tilled_tiles)
2. Tile belum ada tanaman (cek tabel crops)
3. User punya bibit seed_code di inventory (quantity >= 1)
4. seed_code valid (ada di items dengan type='seed')

Aksi:
- Kurangi bibit di inventory
- Insert ke crops: user_id, tile_x, tile_y, item_id, stage='seed', water_level=100, planted_at=now
- Return crop yang baru dibuat

FRONTEND:
- Flow: tekan E di tile tilled → buka mini-menu pilih bibit
  * Atau: pakai hotbar (pilih bibit di slot, tekan E di tile tilled)
- Setelah tanam: sprite tanaman kecil (stage seed) muncul di tile
- Update inventory (bibit berkurang)

DELIVERABLE:
- Endpoint POST /plant dengan PlantService
- Mini-menu pilih bibit (React)
- Integrasi hotbar → plant
- Render crop di Phaser (stage seed)
- Notifikasi
