Setup proyek game bertani pixel art 2D dengan arsitektur terpisah:

STRUKTUR FOLDER:
project-root/
├── frontend/   (React + Phaser 3 + TypeScript + Vite)
├── backend/    (Laravel 11 API)
└── README.md

FRONTEND SETUP:
- Vite + React 18 + TypeScript
- Install: phaser, zustand, @tanstack/react-query, axios, tailwindcss
- Tailwind CSS untuk UI overlay
- Folder: src/game (Phaser), src/ui (React), src/api, src/stores, src/hooks, src/types

BACKEND SETUP:
- Laravel 11 + Sanctum
- MySQL
- Folder tambahan: app/Services (game logic), app/Http/Controllers/Api/V1
- API versioning: /api/v1/...

KONVENSI:
- Semua response API format: { success, message, data }
- TypeScript strict mode aktif
- Setiap aksi game = 1 endpoint POST
- Semua logika game di backend (server-authoritative)

DELIVERABLE:
1. Struktur folder lengkap
2. File konfigurasi (package.json, composer.json, tsconfig, tailwind.config, vite.config, .env.example)
3. README cara setup & run
4. Script npm & composer untuk dev

JANGAN buat fitur gameplay dulu — hanya setup & boilerplate.
