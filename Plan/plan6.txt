Buat UI overlay React di atas canvas Phaser:

KOMPONEN:
1. HUD (pojok kiri atas):
   - Koin: 💰 100
   - Username
   - Tools aktif

2. Hotbar (bawah tengah):
   - Slot 1-9
   - Icon item + jumlah
   - Klik atau tekan angka untuk pilih
   - Highlight slot aktif

3. Inventory Panel (toggle dengan I):
   - Grid item dengan icon + jumlah
   - Klik item → detail + tombol "Pakai" atau "Tanam"
   - Close dengan ESC atau I lagi

4. Shop Panel (muncul saat interaksi dengan toko):
   - Tab "Beli" dan "Jual"
   - List item + harga + tombol aksi
   - Input quantity

5. Sell Panel (bagian dari Shop, tab "Jual"):
   - List hasil panen di inventory
   - Harga jual per unit
   - Tombol "Jual Semua" atau per item

6. Notifikasi Toast (kanan atas):
   - Sukses (hijau): "Berhasil menanam wortel"
   - Error (merah): "Koin tidak cukup"
   - Auto dismiss 3 detik

STATE MANAGEMENT (Zustand):
- useGameStore: coins, inventory, tools, crops, activeHotbarSlot
- useUiStore: isInventoryOpen, isShopOpen, notifications[]
- Actions: addNotification, setCoins, updateInventory, dll

STYLING:
- Tailwind CSS
- Font: "Press Start 2P" dari Google Fonts
- Tema: pixel art, border tebal, warna retro

DELIVERABLE:
- Semua komponen di src/ui/
- Zustand stores di src/stores/
- Tailwind config dengan font pixel
- Integrasi dengan Phaser via event emitter atau Zustand
