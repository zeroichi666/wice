Buat migrations & models Laravel untuk game farming:

TABEL users:
- id, username (unique), email (unique), password
- coins (integer, default 100)
- level (integer, default 1)
- timestamps

TABEL items (master data, di-seed):
- id, code (unique, mis. "carrot_seed"), name
- type: enum('seed','tool','crop')
- buy_price, sell_price (integer, nullable)
- growth_time (integer, detik, untuk seed)
- sprite_key (string, untuk frontend)
- timestamps

TABEL inventories:
- id, user_id (FK), item_id (FK), quantity (integer)
- unique(user_id, item_id)

TABEL crops:
- id, user_id (FK)
- tile_x, tile_y (integer, posisi di map)
- item_id (FK ke items, jenis tanaman)
- stage: enum('seed','sprout','growing','ready')
- water_level (integer 0-100)
- planted_at, last_watered_at, harvested_at (timestamps)
- unique(user_id, tile_x, tile_y)

TABEL transactions (audit log):
- id, user_id (FK)
- type: enum('buy','sell','harvest','plant')
- item_id (FK, nullable)
- quantity (integer)
- amount (integer, delta koin)
- metadata (json)
- timestamps

MODELS:
- User (hasMany inventories, crops, transactions)
- Item
- Inventory (belongsTo user, item)
- Crop (belongsTo user, item)
- Transaction

SEEDER:
- Isi tabel items dengan:
  * carrot_seed (10, -, 30s)
  * tomato_seed (20, -, 60s)
  * corn_seed (35, -, 90s)
  * hoe (50, -, -, tool)
  * watering_can (75, -, -, tool)
  * harvest_basket (100, -, -, tool)
  * carrot (sell 25, crop)
  * tomato (sell 60, crop)
  * corn (sell 120, crop)

DELIVERABLE:
- Semua file migration
- Semua model dengan relasi & fillable
- Seeder ItemSeeder
- Jalankan `php artisan migrate --seed` sukses
